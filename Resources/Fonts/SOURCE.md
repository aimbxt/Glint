# Pixelify Sans

Source: https://github.com/google/fonts/tree/main/ofl/pixelifysans

The unmodified `PixelifySans[wght].ttf` is stored as `PixelifySans.ttf`. The SIL Open Font License is retained in `OFL.txt` and is bundled with the app. Registration uses the process scope only; the font is not installed system-wide. No font download occurs at runtime.
